# 생태자연도 등급별 면적 산정 도구 (브라우저 버전)

**바로 쓰기: https://seungw002799-max.github.io/ecozm-web/**

설치 없이 브라우저(크롬/엣지)에서 바로 실행됩니다.

## 기능
- 사업지구 / 계획지구 / 사업노선 / 계획노선 도면 업로드: DWG, DXF, SHP(zip), GeoJSON
  - DWG도 변환 없이 바로 읽음 (LibreDWG WebAssembly)
- 좌표계 자동 판정 (EPSG:5186/5185/5187/5188, 구 Bessel 5174 등, UTM-K), 수동 변경 가능
- 국립생태원 생태자연도 API에서 최신 자료 확인 후 등급별(1·2·3등급, 별도관리지역) 면적표 → 엑셀 저장 / 표 복사
- 브이월드 배경(일반지도 / 위성지도 / 흰색 배경) 위 도면 출력: 도면 크기(mm) 자유 입력, 방위표·축척바·범례, PNG/PDF 저장

## 처음 쓸 때
1. 작업 탭 > 설정에 공공데이터포털 인증키(국립생태원_생태자연도 서비스, 15057288)와 브이월드 인증키를 넣고 저장
   - 키는 각자 브라우저에만 저장되고 이 저장소에는 올라가지 않습니다.
2. 도면을 끌어다 놓기 → 구분·경계 레이어 확인 → 면적 계산 → 도면 출력

## 개인정보 / 보안
- 도면 파일은 서버로 업로드되지 않고 사용자 PC 브라우저 안에서만 처리됩니다.
- 외부로 나가는 요청은 생태자연도 API(공공데이터포털)와 브이월드 배경지도 타일뿐입니다.

## 계산 기준
- 면적은 EPSG:5186(GRS80 중부원점) 평면좌표 기준
- 등급이 겹치면 별도관리지역 > 1등급 > 2등급 > 3등급 순으로 배정
- "자료 없는 지역은 3등급으로 산정" 옵션(기본 켬): 자연환경보전법 제34조 기준. 해상 사업은 끄고 사용

## 사용 라이브러리
OpenLayers, proj4js, JSTS, jsPDF, dxf-parser, shpjs, ExcelJS, @mlightcad/libredwg-web(GPL-3.0), 글꼴 KoPub돋움체
